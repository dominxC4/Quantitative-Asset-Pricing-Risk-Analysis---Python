# Quantitative Asset Pricing & Risk Analysis

A Python-based analysis of 2025 daily financial data covering asset pricing, return forecasting, and fixed-income risk.

### Key Areas
- Fama–French three-factor regression
- ARIMA time-series forecasting of stock returns
- Bond pricing, Macaulay duration, and modified duration
- Visualizations and residual diagnostics

**Tools:** Python, Pandas, NumPy, Matplotlib, Statsmodels
